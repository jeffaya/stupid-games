Guitar Fretboard Hero V10.2.0 — Final Engine Extraction / Config Bootstrap

Deployment configuration
- Added site.config.json. Change only its "instrument" value to select the site profile.
- Added bootstrap.js. It loads site.config.json with cache: "no-store", then loads the matching instrument/product and the shared app.
- Added README.md documenting supported configuration values and deployment principle.
- Unknown instrument values produce an explicit configuration error.

Core extraction
- Added core/tuning.js.
- Added core/fretboard-layout.js and routed shared fretboard geometry through it.
- Added core/mode-registry.js; Practice MODE and FRETBOARD choices are now generated from the active instrument profile.
- Added core/arpeggio-engine.js.
- Added core/chord-engine.js.
- Extended core/quiz-engine.js with generic rank lookup.

Product extraction
- Removed the 30 Guitar rank names/copy from app.js.
- Moved the full approved Guitar rank ladder to products/guitar-fretboard-hero.js.
- app.js now reads the active product selected by bootstrap.js rather than hard-coding the Guitar product.
- Share title/name/URL now come from the active product config.
- Added product scaffolds for Ukulele and 12-string Guitar.

Important validation boundary
- Guitar remains the behavior/visual reference and is the configuration intended for regression testing in this package.
- Bass, Ukulele and 12-string profiles are architecture scaffolds. Their instrument-specific learning geometry/content is not declared production-complete by this refactor.
- No instrument-specific branch was added to /core.
