Guitar Fretboard Hero V10.0.0 — Reusable Fretboard Engine

Architecture
- Extracted instrument-specific data to instrument-profiles.js.
- Extracted reusable instrument/fretboard math to fretboard-engine.js.
- app.js now consumes the active instrument profile instead of assuming six strings in core rendering loops.
- Shared fret/string geometry adapts to the configured string count.
- Shared inlay placement adapts to the configured string count.
- String gauges/wound-string rendering are profile driven.

Guitar profile
- Standard E A D G B E tuning.
- Guitar fret options and max fret.
- Guitar triad string groups.
- Guitar-specific five pentatonic position geometry.
- Guitar-only CAGED templates/anchors.

Bass readiness
- Triads are NOT guitar-only: bass uses the same 1–3–5 / 1–b3–5 harmonic structures, with bass-appropriate string groups/voicings.
- CAGED remains explicitly guitar-only and is not part of the reusable engine.
- A future bass profile can provide E A D G (or 5/6-string tunings), bass pentatonic geometry and bass practice modes without forking the core renderer/menu architecture.

No intended UX/gameplay change for the current guitar site.
V9.4.5 remains the visual/functional baseline for comparison.
